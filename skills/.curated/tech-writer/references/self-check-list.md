# 翻译自检清单

本清单用于翻译完成后的自检阶段。逐条检查，全部通过后方可提交。未通过项需修复后重新检查。

## 结构完整性

- [ ] 代码块数量与英文源文件一致
- [ ] 代码块内容（除纯注释行外）与英文源文件逐字节一致
- [ ] 占位符（`$VAR`、`${VAR}`、`{{variable}}`、`<tag>` 等）完全一致
- [ ] YAML frontmatter key 集合不变，顺序一致
- [ ] `<system-reminder>` 标签数量和配对一致
- [ ] 链接和路径未被翻译
- [ ] 转义反引号保持转义形式

## 术语一致性

- [ ] 同一术语全文仅一种写法
- [ ] 专名保持官方拼写（Anthropic、Claude、Claude.ai、Claude Code）
- [ ] 每节结束处有术语变更记录（发布级模式）
- [ ] 文末有全局术语与专名一致性表（发布级模式）

## 排版规范

- [ ] 中英文之间有半角空格
- [ ] 无破折号字符（`—` `–` `--`）
- [ ] 列表符号统一使用 `-`
- [ ] 代码块标注语言

## 翻译质量

- [ ] 自然语言翻译准确，无漏译
- [ ] 无机翻痕迹（语序不自然、主语缺失）
- [ ] 无过度意译（改变原文事实边界）
- [ ] HTML 注释头标记已添加

## 验收脚本

- [ ] `verify.sh` 通过
- [ ] `check_translation_lock.py` 通过（发布级模式）

---

如果某项不适用（例如非发布级模式不需要术语变更记录），在该项后标注「不适用」及原因。
