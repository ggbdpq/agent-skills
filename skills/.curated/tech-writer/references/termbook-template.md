# 全局术语与专名一致性表模板

## 术语表（统一译法）

| 英文术语 | 统一中文写法 | 说明 |
|---|---|---|
| skill | Skill | 产品术语，单数 |
| skills | Skills | 产品术语，复数 |
| system card | 系统卡 | 与 Anthropic 文档口径保持一致 |
| responsible scaling policy | 负责任扩展政策 | 政策名固定写法 |

## 专名一致性表

| 专名 | 统一写法 |
|---|---|
| Anthropic | Anthropic |
| Claude | Claude |
| Claude.ai | Claude.ai |
| Claude Code | Claude Code |
| Claude Agent SDK | Claude Agent SDK |

## 句式与风格统一约定

| 项目 | 统一规则 |
|---|---|
| 句式长度 | 以短句为主，长句按“结论 + 说明”拆分 |
| 语气 | 以技术陈述句为主，避免口号化与感叹式表达 |
| 标点 | 中文叙述用中文标点；代码与路径保留英文符号 |
| 术语 | 同一文档只保留一种主写法 |

## 使用说明

### 何时使用本模板

在发布级翻译模式下，翻译开始前复制本模板到工作目录，作为术语管理的基础文件。翻译过程中逐步填充术语条目。

### 填写步骤

1. 翻译前：将已知的专名和固定术语填入"术语表"和"专名一致性表"
2. 翻译中：每遇到新术语，先查表确认是否已有统一写法；如无，新增条目
3. 翻译后：检查全文，确保所有术语与本表一致

### 填写示例

假设翻译一篇关于 Claude Code 的文档，术语表可能如下：

| 英文术语 | 统一中文写法 | 说明 |
|---|---|---|
| approval mode | 审批模式 | Claude Code 的权限控制机制 |
| slash command | 斜杠命令 | 以 `/` 开头的交互式命令 |
| context window | 上下文窗口 | 模型单次对话可处理的 token 范围 |
| tool use | 工具调用 | 模型调用外部工具的能力 |

### 术语冲突处理

当同一英文术语有多种候选译法时：

1. 列出所有候选项及其来源（官方文档、社区惯例、行业标准）
2. 选定一种作为锁版口径
3. 在"说明"列记录选定原因和排除的候选项
